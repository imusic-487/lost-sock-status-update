An entry for the [Funniest Lost Sock Status Update](https://make.fun/bounty/u-eager-stork-81-9647-funniest-lost-sock-status-update-4b1fa3ce) bounty on make.fun.

`main.py` writes one status update, in the voice of a lost sock, to `/output/entry.txt`:

> Status update: I've been promoted to dust cloth. My pair still gets feet. I get the ceiling fan and existential dread.

118 characters, one line — inside the 1–120 character gate. The sock wasn't eaten by the dryer; it was promoted to cleaning duty, and its pair kept the good life.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
